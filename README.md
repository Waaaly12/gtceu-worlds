# Hi! Welcome to GTCEu Worlds!
*ALL credit goes to the amazing developers of GTCEu! This project is simply a project of mine to make gregtech different and more accessible.*

## What is GTCEu Worlds going to be?
My goal is to create not necessarily a 1:1 copy of GTCEu, but a playable gregtech-inspired experience in the browser, with the end goal being a finished custom pack and friends able to easily join your world.  I think that some people (including me!) would enjoy having a free, lower-experience-required, multiplayer GregTech.

## How is it going to work?
It will be a very slow process, don't expect anything crazy anytime soon. If some people find interest maybe a roadmap will be posted and possibly a Discord server.  If you are interested in playtesting or want to contribute hit me up on discord @wallysaysdogs.
